From Metal Typer to the

A comparison of typesetting, desktop publishing, HTML and CSS

Old Fashioned Typesetting

Traditional typesetting was a physical craft. A typesetter picked individual pieces of metal type, one letter at a time, and arranged them in a frame to form lines, paragraphs and pages. Spacing was adjusted by hand with small metal spacers, and a mistake meant replacing the the piece of type. Once the page was inked and printed, the layout was fixed.

Desktop Publishing

Desktop Publishin moved the same job onto a computer. Designers arrange text and images ona virtual page, see the result on screen as it will be printed, and change anything instantly. Like metal type, desktop publishing is built around a fixed page size, so the final product is still a printed pdf page whose layout is decided by the designer.

HTML and CSS

HTML and CSS take a different approach to the same thing. HTML describes the structure and meaning of the content, such ass headings, paragraphs and lists, while CSS describes how that content should look. There is no fixed page. The browser lays the content out to suit the screen and reader's settings.

Smiliarities and differences

All three approaches share the same goals: readable text, clear herarchy and good use of space and typefaces. They differ in how much control the creator has. Metal tyoe and desktop publishing give exact control over a fixed page, While HTML and CSS trade some of that precision for flexibility, since the same content can adapt to a phone a tablet or a large monitor. Changing a design has also become far easier, from rebuilding a page by hand, to editing a layout file, to changing a single CSS rule.
